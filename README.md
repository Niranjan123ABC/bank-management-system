# Bank Management System

A console-based banking application built with Java and JDBC to manage customer accounts and transactions.

## Features
- Account creation and management with validation
- Deposit and withdrawal operations with balance checks
- Balance inquiry
- Transaction history tracking
- Secure database integration using JDBC

## Tech Stack
Java, JDBC, YOUR_DATABASE, OOP

## How to Run
1. Install Java and YOUR_DATABASE.
2. Create a database named `YOUR_DATABASE_NAME` and the required tables (see `schema.sql`, if included).
3. Open the database connection class and set your own database username and password.
4. Compile and run the main class: `YOUR_MAIN_CLASS`.
